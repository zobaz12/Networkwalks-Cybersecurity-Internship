Week 01 - Cybersecurity Lab Setup

Assignment Information

- Training Provider: NetworkWalks.
- Assignment Title: Lab Setup — VirtualBox and Kali Linux.
- Status: Completed.

1. Objective:

The objective of this assignment was to establish a cybersecurity testing lab environment on a personal computer using Oracle VirtualBox and Kali Linux.

The lab provides a virtualized environment for future cybersecurity and ethical hacking practical exercises.


2. Tools and Technologies:

- Oracle VirtualBox.
- Kali Linux.
- Windows 10 (Host Operating System).
- NAT Network.
- Linux Terminal.

3. Lab Configuration:

Component| Configuration
Host OS| Windows 10
Virtualization Platform| Oracle VirtualBox
Virtual Machine| Kali Linux
Network Type| NAT Network
Network Subnet| 10.0.0.0/24
Kali Linux IP Address| 10.0.0.2/24
Shared Folder| downloads
Clipboard| Bidirectional
Drag and Drop| Bidirectional

4. Implementation Tasks:

- Imported Kali Linux into Oracle VirtualBox.
- Created and configured a NAT Network using the specified subnet.
- Connected the Kali Linux virtual machine to the configured NAT Network.
- Assigned the required static IP address.
- Verified internet connectivity.
- Enabled bidirectional shared clipboard and drag-and-drop functionality.
- Configured a shared folder named "downloads" between the host and virtual machine.
- Created a virtual machine snapshot after completing the configuration.

5. Challenges and Troubleshooting:

During the implementation, I encountered two main challenges:

- Challenge 1: Kali Linux Import Issues

Initially, I faced difficulties importing the Kali Linux virtual machine into VirtualBox.

Resolution: I downloaded an alternative Kali Linux virtual machine image and successfully imported it into VirtualBox.

- Challenge 2: Network Configuration Issues

After importing Kali Linux, I encountered difficulties configuring the virtual network and establishing the required network connectivity.

Resolution: I investigated the network settings, reviewed the NAT Network configuration, and resolved the encountered configuration issues until the required lab setup was successfully completed.

6. Learning Outcomes:

Through this assignment, I gained practical experience in virtualization, Kali Linux deployment, virtual networking, static IP configuration, network troubleshooting, virtual machine integration, and technical documentation.

I also improved my problem-solving skills by resolving installation and networking issues encountered during implementation.
